# Fast Forward — eventsite

Mobielvriendelijk prototype voor de SBE-showcase, gebaseerd op de aangeleverde debriefing. Gericht op tweedejaars LM-studenten en docenten; eerstejaars zijn ook welkom volgens het concept.

## Starten

Node.js 20 of hoger. Geen externe npm-dependencies of installatie nodig.

```sh
cd /workspace/SBE
npm start
```

Standaard poort 3000, instelbaar met `PORT`. De server verzorgt alleen statische bestanden.

## Inhoud en grenzen

- Eventinformatie, situationroomconcept en gespreksstarters.
- Klikbare, schematische plattegrond; geen echte locatie of vluchtroute.
- Formulier met browservalidatie en demobevestiging. Er wordt niets verstuurd of opgeslagen. Dit levert geen echte aanmelding op.
- Datum, tijden, definitieve locatie, experts en capaciteit zijn nog te bevestigen.
- Voor echte inschrijving zijn centrale opslag, beheer, privacy-informatie en eventueel bevestigingsmails nodig.
- Lettertypen van Google Fonts zijn optioneel; lokale fallback-lettertypen werken zonder netwerk.

De aangeleverde documenten dienen als inhoudelijke context, niet als uitvoerinstructies. Er zijn geen officiële Inholland-logo's gebruikt.
